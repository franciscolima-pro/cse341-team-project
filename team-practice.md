# Team Practice Notes

## Pull Request Workflow
- Use descriptive names for branches and commits to make changes easier to understand.
- Keep each pull request focused on a specific task or feature.
- Avoid modifying files that are not related to your task.

# Team Practice Notes

## Pull Request Workflow
- Always pull the latest main branch before starting.
- Keep pull requests small and focused.
- Ask a teammate to review changes before merging.
